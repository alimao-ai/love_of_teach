## 1. 产品概述

爱教学是面向高校教学质量管理的单机演示平台，覆盖课程基础数据、开课情况、教学资源、课程评价、督导覆盖和资源建设统计。

平台支持以下核心链路：

```text
管理员维护基础数据并导入课程
-> 教师查看课程、上传章节化资源、订阅变更通知
-> 督导查看覆盖情况、创建听评课计划、评价课程和评审资源
-> 主任查看学院钻取、评价汇总、资源覆盖并导出报表
```

## 3. 环境要求

课程演示建议环境：

- Windows 10/11 或 Linux
- Java 17 或更高版本
- Node.js 22 和 npm
- Chrome 或 Edge 新版浏览器
- 可用端口：`8080`、`5173`
- 至少 1 GB 可用磁盘空间

仓库根目录为 `code`，命令均在 `code` 下执行。

## 4. 启动系统

### 4.1 启动后端演示环境

```powershell
cd backend
.\mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=dev
```

`dev` 配置会：

- 初始化幂等演示数据
- 创建演示账号
- 开放 H2 控制台
- 设置教师注册邀请码为 `TEACH-DEMO-2026`

后端启动成功后访问 `http://localhost:8080/api`。

### 4.2 启动前端

打开第二个终端：

```powershell
cd frontend
npm ci --no-audit
npm run dev
```

浏览器访问：

```text
http://localhost:5173
```

系统首先显示登录页，不会直接进入业务工作区。

### 4.3 停止系统

在前端和后端终端分别按 `Ctrl+C`。

Windows 下如果 Maven Wrapper 提示：

```text
Terminate batch job (Y/N)?
```

输入 `Y` 并回车。

### 4.4 安全默认配置

不指定 profile 时：

- 不创建演示账号
- 不开放 H2 控制台
- 教师公开注册默认关闭

非演示环境至少需要配置：

```powershell
$env:TEACHER_REGISTRATION_CODE = "替换为随机邀请码"
$env:APP_SEED_ENABLED = "false"
$env:H2_CONSOLE_ENABLED = "false"
cd backend
.\mvnw.cmd spring-boot:run
```

首次生产化部署的管理员、督导和主任账号目前尚未提供页面化创建功能，需要部署方通过受控初始化或数据迁移预先创建。不要在正式环境长期使用演示账号。

## 5. 登录与注册

### 5.1 登录

1. 打开 `http://localhost:5173/login`。
2. 输入用户名和密码。
3. 登录成功后，系统根据角色显示不同菜单。
4. 右上角显示当前姓名和角色。
5. 点击退出图标可注销当前令牌并返回登录页。

登录失败 5 次后，同一账号和来源地址会被限制 15 分钟，接口返回 429。

### 5.2 演示账号

| 角色 | 用户名 | 密码 | 绑定教师 |
|---|---|---|---|
| 教师 | `teacher` | `teacher123` | 张明 |
| 教师 | `teacher2` | `teacher123` | 李华 |
| 督导 | `supervisor` | `supervisor123` | 无 |
| 主任 | `director` | `director123` | 无 |
| 管理员 | `admin` | `admin123` | 无 |

演示账号只用于本地 `dev` 环境，不应出现在正式部署中。

### 5.3 教师注册

1. 在登录页点击“注册新账号”。
2. 填写用户名、姓名、教师工号、邀请码和密码。
3. 邀请码必须与后端配置一致。
4. 一个教师工号只能绑定一个账号。

`dev` 环境邀请码为：

```text
TEACH-DEMO-2026
```

正式环境通过 `TEACHER_REGISTRATION_CODE` 设置邀请码。未配置时注册接口返回 403。

## 6. 通用页面

### 6.1 课程查询

可按以下条件筛选：

- 学期
- 院系/教研室
- 教师
- 课程代码、课程名称或教师姓名关键字

点击课程行进入课程详情。课程详情展示：

- 课程代码、名称、学分和简介
- 授课教师、班级、学期和学生人次
- 开课状态和督导状态
- 章节和教学资源

### 6.2 教学资源检索

所有登录角色都可检索已上架资源。

筛选条件：

- 学期
- 院系
- 资源类型
- 关键字

下架资源不会出现在普通检索结果中。任课教师仍可在课程详情中看到并恢复。

## 7. 教师操作

### 7.1 创建章节

1. 打开本人所授课程详情。
2. 滚动到“教师资源管理”。
3. 填写章节名称、章节顺序和章节说明。
4. 点击“创建章节”。

章节顺序用于课程详情中的展示排序。

### 7.2 上传资源

1. 在课程详情选择“上传教学资源”。
2. 填写资源名称和说明。
3. 选择资源类型：文档、课件或视频。
4. 选择所属章节。
5. 选择文件并上传。

允许扩展名：

```text
pdf, doc, docx, ppt, pptx, xls, xlsx, txt, md, mp4, webm, zip
```

单文件上限为 10 MB。系统会校验扩展名和文件头，内容不匹配时拒绝上传。

### 7.3 下架和恢复资源

1. 打开本人课程详情。
2. 在资源右侧点击下架图标。
3. 输入下架原因并确认。
4. 普通资源库将不再显示该资源。
5. 点击恢复图标可重新上架。

### 7.4 课程通知

1. 进入“课程通知”。
2. 在课程订阅列表点击“订阅”。
3. 管理员导入课程或开课数据并实际发生变更后，系统生成通知。
4. 点击“全部已读”可清空未读计数。
5. 点击“退订”后不再接收该课程的新通知。

重复导入完全相同的数据不会产生重复通知。

### 7.5 查看本人评价反馈

进入“我的反馈”，可查看：

- 本人课程数
- 评价数量
- 平均评分
- 课程评分明细
- 最新评语和评价时间

教师不能查看其他教师课程的评价明细。

## 8. 督导和主任操作

### 8.1 查看督导覆盖率

进入“督导覆盖”，可按学期和院系查看：

- 开课数
- 已督导数
- 待督导数
- 学生人次
- 督导覆盖率
- 课程督导清单

### 8.2 学院课程钻取

进入“学院钻取”，选择学期和学院后查看：

- 学院开课数
- 学生人次
- 已督导和待督导课程
- 督导覆盖率
- 课程明细

点击课程可进入详情。

### 8.3 创建听评课计划

1. 进入“听评课计划”。
2. 选择开课记录、计划日期和截止日期。
3. 填写本次计划说明。
4. 点击“创建计划”。
5. 待执行计划可点击“开始执行”。
6. 进行中计划可点击“完成计划”。

完成计划会生成督导记录。同一开课记录只保留一条督导记录，重复完成不会虚增覆盖率。

逾期未完成的计划会标记“已逾期”。

### 8.4 给课程打分

1. 进入“课程评价”。
2. 选择课程。
3. 输入 0 至 100 分和评语。
4. 点击“提交评价”。

同一评审人对同一课程再次提交会更新原评价。

### 8.5 查看评价汇总

进入“评价汇总”，可按学期和院系查看：

- 已评课程数
- 评价总数
- 总体平均分
- 薄弱课程数
- 课程平均分和最新评语

平均分低于 70 分的课程标记为薄弱课程。

### 8.6 资源质量评审

1. 进入“教学资源”。
2. 选择资源并点击“评审”。
3. 选择质量等级：优质、合格、待改进。
4. 填写评审意见。
5. 可勾选“推荐为优质资源”。
6. 点击“保存评审”。

资源库会展示质量等级和推荐状态。

### 8.7 查看资源覆盖率

进入“资源覆盖率”，可按学期和院系查看：

- 开课总数
- 已有资源课程数
- 已上架资源数量
- 课程覆盖率
- 学院覆盖汇总
- 未覆盖课程清单

只有已上架资源计入覆盖率。

## 9. 主任导出报表

1. 进入“统计导出”。
2. 选择学期、院系和教师筛选条件。
3. 点击下载开课统计 CSV。

报表包含课程、院系、教师、学期、班级、学生人次、状态、资源数、督导状态和平均评分。公式前缀会自动转义。

## 10. 管理员操作

### 10.1 维护院系和学期

进入“基础配置”：

- 新增或编辑院系
- 新增或编辑学期
- 启用或停用数据

停用后历史引用保留，但相关数据不再作为新增业务的可选项。

### 10.2 批量导入课程与教师

1. 进入“批量导入”。
2. 下载 CSV 模板。
3. 按模板填写数据。
4. 选择文件并点击“开始导入”。
5. 查看成功数、失败数和逐行失败原因。
6. 可下载失败原因 CSV 后修正重试。

CSV 字段：

```text
courseCode,courseName,departmentCode,credits,description,teacherNo,teacherName,
semesterCode,className,studentCount,status
```

字段规则：

- 除 `description` 外均为必填。
- `credits` 必须是非负数字。
- `studentCount` 必须是非负整数。
- `status` 支持 `PLANNED`、`OPEN`、`CLOSED` 或对应中文。
- 每一行使用独立事务，失败行不会影响其他成功行。

## 13. 常见问题

### 13.1 登录返回 401

检查用户名和密码，确认账号已初始化且未停用。

### 13.2 页面功能返回 403

当前账号没有对应角色权限，或教师尝试操作非本人课程。

### 13.3 连续登录失败后无法登录

触发登录限流，等待 15 分钟后重试，或重启单机开发服务清空进程内计数。

### 13.4 注册提示邀请码无效

检查前后端运行环境是否一致。`dev` 默认邀请码为 `TEACH-DEMO-2026`；正式环境检查 `TEACHER_REGISTRATION_CODE`。

### 13.5 注册提示教师工号已绑定

一个教师档案只能绑定一个账号。需要由管理员确认是否已存在历史账号。

### 13.6 没有演示账号

未使用 `dev` profile，或 `APP_SEED_ENABLED` 为 false。演示环境按第 4.1 节启动。

### 13.7 H2 控制台返回 404

H2 控制台默认关闭。仅在 `dev` profile 下访问 `http://localhost:8080/h2-console`。

### 13.8 上传失败

检查文件是否超过 10 MB、扩展名是否允许、文件内容与扩展名是否匹配，以及当前教师是否拥有该课程。

### 13.9 CSV 导入失败

检查必填字段、学分、学生人数、开课状态、院系编码、学期编码和教师工号。下载失败原因 CSV 查看逐行错误。

### 13.10 端口被占用

关闭占用 `8080` 或 `5173` 的旧进程，或调整后端端口并在 `frontend/vite.config.ts` 更新代理目标。

## 14. 数据与安全说明

- H2 数据文件位于 `backend/data/`。
- 上传文件位于 `backend/uploads/` 或配置的 `app.upload-dir`。
- 停止服务后应备份上述目录。
- 当前令牌保存在 localStorage，正式系统应迁移到 HttpOnly Cookie。
- H2 控制台只用于本地开发，不能暴露到公网。
- 当前文件存储、病毒扫描、限流和数据库迁移限制详见 `docs/technical-debt-register.md`。

## 15. 当前限制

- 未提供密码找回、修改密码和账号禁用页面。
- 未提供管理员创建督导、主任和管理员账号的页面。
- 不支持多实例文件共享。
- 不支持课堂录像 AI 分析、抬头率识别和个性化建议。
- 当前版本定位为课程演示和验收版本，不是正式生产发行版。
