## 已交付用户故事

| 编号 | 交付内容 | 验收结果 |
|---|---|---|
| US06 | 督导按学院汇总并钻取课程数据 | 汇总数据与 `/api/courses` 使用同一课程查询源，跨院系授课按课程所属学院统计 |
| US09 | 教师订阅、退订和查看课程变更通知 | 仅可订阅本人所授课程；课程或开课数据实际变化时生成通知；支持全部已读 |
| US11 | 听评课计划与执行进度跟踪 | 支持待执行、进行中、已完成、逾期和取消状态；完成计划联动督导记录 |
| US14 | 教师下架/恢复过时资源 | 下架后普通资源检索不可见，任课教师仍可在课程详情查看并恢复 |
| US15 | 督导/主任资源质量评审和推荐 | 支持优质、合格、待改进等级，评审意见和推荐状态在资源库展示 |
| US16 | 课程资源覆盖率统计 | 只统计已上架资源，按学院汇总并将未覆盖课程优先展示 |

## 技术债处理

- 已偿还：督导记录按开课记录唯一；计划完成先锁定开课记录，数据库唯一约束兜底。
- 已偿还：课程学院筛选改为课程所属院系，避免按授课教师院系错误归类。
- 已偿还：资源质量评审在课程详情使用批量查询，避免逐资源查询造成 N+1。
- 已偿还：重复导入相同课程/开课数据不生成重复通知。
- 发布后债务：登录失败次数限流、对象存储、病毒扫描、HttpOnly Cookie、正式数据库迁移审计。

## 启动与验证

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

```powershell
cd frontend
npm run dev
```

访问 `http://localhost:5173`，系统首先进入登录页。后端 API 位于 `http://localhost:8080/api`，H2 控制台位于 `http://localhost:8080/h2-console`。
