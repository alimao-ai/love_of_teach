## 缺陷关闭情况

| 缺陷 | 影响 | 修复结果 |
|---|---|---|
| H2 控制台默认暴露 | 未登录用户可能访问数据库控制台 | 默认关闭，仅 `dev` 配置开放 |
| 演示账号和种子默认启用 | 已知密码账号可能进入非演示环境 | 默认关闭种子，`dev` 配置按需启用 |
| 教师注册可冒用工号 | 仅凭公开工号可能绑定教师身份 | 增加注册邀请码、教师档案唯一约束和冲突处理 |
| 失败 CSV 公式注入 | Excel 打开失败报告可能执行公式 | 统计导出和失败 CSV 共用安全转义 |
| 统计接口权限不一致 | 教师可访问督导覆盖数据 | 限制为督导、主任和管理员 |
| 外部链接未校验 | 可能形成非 HTTP/HTTPS 跳转 | 仅允许绝对 HTTP/HTTPS 地址 |
| 非法媒体类型导致 500 | 下载异常数据可能返回服务端错误 | 回退为二进制流并设置 `nosniff` |
| 并发注册/订阅/评审冲突 | 唯一约束触发时返回 500 | 统一转换为 409 数据冲突 |
| 登录暴力尝试 | 无失败次数限制 | 5 次失败后限流 15 分钟 |
| 学分缺失静默写 0 | 导入数据可能失真 | 学分改为必填 |
| 同一开课重复督导记录 | 覆盖率虚高 | 悲观锁和数据库唯一约束双重保护 |
| 跨院系课程归属错误 | 学院筛选和钻取不准确 | 改为按课程所属院系筛选 |
| UTF-16 文本被误拒 | 合法文本无法上传 | 支持带 BOM 的 UTF-16/UTF-32 文本 |
| 事务失败遗留孤儿文件 | 磁盘存在无数据库记录文件 | 回滚完成后自动清理 |
| 内部迭代文案出现在产品界面 | 用户会看到“Sprint 3”“进阶 1”等开发阶段名称 | 登录页和侧边栏改为正式产品文案，内部文档保留 Sprint 追溯编号 |

## 技术债处理

- 已偿还：督导记录按开课记录唯一；计划完成先锁定开课记录，数据库唯一约束兜底。
- 已偿还：课程学院筛选改为课程所属院系，避免按授课教师院系错误归类。
- 已偿还：资源质量评审在课程详情使用批量查询，避免逐资源查询造成 N+1。
- 已偿还：重复导入相同课程/开课数据不生成重复通知。
- 已偿还：默认关闭演示种子与 H2 控制台，教师注册增加邀请码和数据库唯一绑定，登录失败增加限流。
- 发布后债务：对象存储、病毒扫描、HttpOnly Cookie、正式数据库迁移审计、分布式登录限流。原因、影响、责任角色和偿还计划见 `docs/technical-debt-register.md`。

.\mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=dev
```

cd frontend

```

## 升级与回滚

升级前应备份 `backend/data/`、`backend/uploads/` 和当前配置。现有数据库如果存在多个账号绑定同一 `teacher_id`，需先清理重复数据，否则新增唯一约束会导致启动失败。

演示环境升级后使用 `dev` profile 启动；非演示环境应显式设置 `TEACHER_REGISTRATION_CODE`，并保持 `APP_SEED_ENABLED=false` 和 `H2_CONSOLE_ENABLED=false`。

如需回滚，可回到上一发布标签 `v1.0.0-sprint3` 并恢复对应数据库和上传目录备份。由于 v1.0.1 增加了表结构约束和配置项，不建议只回滚程序而不恢复数据库备份。

## 已知限制

- 生产环境首批管理员、督导和主任账号尚未提供页面化创建流程，需要部署方通过受控初始化或数据迁移完成。
- 当前没有密码找回、修改密码和账号禁用管理页面。
- H2、单机文件存储、localStorage 令牌和单进程限流不满足正式生产部署要求。
- 剩余技术债、责任角色和偿还计划见 `docs/technical-debt-register.md`。
